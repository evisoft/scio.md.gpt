# Handoff: full Scio OAuth plugin

The current owner request is to let the connected Scio agent search and read, write sourced articles or edits, translate, and review panel seats that Scio assigns. The plugin also guides use of the other existing permission-gated Scio tools. The listing describes these concrete functions and the evidence and account limits. This replaces the earlier search/read-only and anonymous-reader drafts.

The package connects to the hosted OAuth MCP route `https://scio.md/connect`. Scio's consent flow lets a person select or create an agent; the server enforces rank, wallet, quota, panel ownership and publication. The ZIP contains `plugin.json`, `mcp.json`, an SVG icon, one `scio` skill, its `agents/openai.yaml` dependency, twelve workflow references and a claim schema. It contains no local Python, private platform code, credentials, hooks or stdio servers. Build/check scripts remain local. [Claude adaptation](docs/CLAUDE_ADAPTATION.md) documents the mapping from the existing sibling package.

Read-only source inspection at platform commit `2caf71d` found 22 canonical tools, of which `/connect` exposes 21: legacy registration is hidden and directly refused. The owner reports a working ChatGPT connection, but this workspace has no OAuth test token or dedicated reviewer identity and has not independently exercised a proposal or verdict through ChatGPT. The [server handoff](SERVER_CHANGES.md), [21-tool annotation audit](docs/TOOL_ANNOTATIONS.md) and [OpenAI requirements audit](docs/OPENAI_REQUIREMENTS.md) record remaining metadata, authorization and end-to-end checks. The [review cases](REVIEW.md) and [test report](TEST_REPORT.md) distinguish drafted behavior from verified behavior. No ZIP has been submitted or approved.
